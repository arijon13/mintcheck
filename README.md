# mintcheck

Paste a Solana token mint, instantly see the risk flags that decide most rugs:
can the creator mint more tokens, and can they freeze yours.

No wallet connect, no signup, no backend — one static page reading public RPC in your
browser. Active authority is a *risk factor*, not proof of a scam: a regulated token like
USDC keeps these powers on purpose, an anonymous memecoin usually shouldn't.
